# UI Design Odyssey // 10 Design Paradigmer

En samling av 10 gjennomførte, interaktive og dedikerte nettsider som demonstrerer de mest distinkte UI-designstilene fra de siste tiårene – fra 90-tallets skeuomorfisme og cyber-estetikk til moderne Bento Grid og Neo-Brutalism.

Inkluderer også et sentralt **UI Design Museum** med en *Metamorphosis Sandbox* der samme grensesnittkomponent forvandles på sekundet mellom alle 10 stiler.

---

## 🎨 De 10 Stilene

1. **🥊 Neo-Brutalism** (`index.html`)  
   Harde sorte rammer, dype kontrastskygger, mettet neon og rå typografi.  
   *Interaktivt*: Live Neo-Styler, 8-bit Arcade Soundboard, retro klistremerker.

2. **🍱 Bento Grid** (`bento.html`)  
   Asymmetriske, modulære ruter inspirert av Apple og Linear.  
   *Interaktivt*: Spotlight-lyskaster som følger musen, sanntids SVG-bølgediagram, `⌘K`-kommandopalett, 90-dagers oppetid-heatmap.

3. **🪟 Glassmorphism** (`glass.html`)  
   Frostet glass (`backdrop-filter: blur`), semitransparente lag og svevende neon-orber.  
   *Interaktivt*: 3D-vippende holografisk bankkort med gjenskinn, live Staking APY-kalkulator.

4. **🪨 Neumorphism (Soft UI)** (`neumorphism.html`)  
   Monokromatiske overflater med myke doble lys-/skyggeprofiler ekstrudert fra bakgrunnen.  
   *Interaktivt*: Hi-Fi 4-bånds grafisk equalizer, stemningsbelysning, smart-termostat.

5. **🪵 Skeuomorphism** (`skeuomorphism.html`)  
   Fysiske teksturer som skinn, treverk, metall og mekanikk.  
   *Interaktivt*: Analog AM/FM-radiotuner med bevegelig frekvensnål, spinnende kassetthjul, dual VU-metere, vintage Rolodex.

6. **🧸 Claymorphism** (`claymorphism.html`)  
   3D-leire, marshmallow-knapper og dype indre skygger.  
   *Interaktivt*: 3D-avatarbygger i sanntid, leir-podium for toppliste, interaktive oppdrag.

7. **📄 Flat Design** (`flat.html`)  
   Minimalistiske 2D-fargeblokker, ingen skygger (Windows Metro / iOS 7-æraen).  
   *Interaktivt*: Windows 8 Charms Bar som glir inn fra høyre, levende fliser, sanntids børs-ticker.

8. **📐 Material Design 3** (`material.html`)  
   Googles Material You med digitalt papir, elevasjon og dynamiske farger.  
   *Interaktivt*: Material You Dynamic Seed-fargevelger som farger om hele appen, Navigation Rail, kalender.

9. **🏛️ Swiss Minimalism** (`minimalism.html`)  
   Strengt typografisk rutenett, ren kontrast og Helvetica/Inter-orden (Zürich 1957).  
   *Interaktivt*: Type-Scale Simulator (juster fonthøyde og tracking i sanntid), arkitekturmonografier.

10. **🕹️ Cyberpunk / Y2K** (`cyberpunk.html`)  
    CRT-scanlines, neonglød i cyan/magenta og vinklede HUD-elementer.  
    *Interaktivt*: Breach Protocol 4x3 hex-hackeminispill, 5-toners synth-tangenter med Web Audio.

---

## 🏛️ Bonus: UI Design Museum (`museum.html`)

Åpne `museum.html` for en interaktiv utstilling. Her kan du teste **Metamorphosis Sandbox** hvor én og samme musikkspiller-widget skifter utseende mellom alle 10 stiler på et millisekund.

---

## 🚀 Kjøre lokalt

Prosjektet er bygget med ren HTML, moderne CSS og vanilla JavaScript – ingen build tools, bundlere eller eksterne biblioteker kreves.

```bash
# Start en enkel lokal server
python3 -m http.server 4321

# Eller åpne filene direkte i nettleseren
open museum.html
```
